# Student Library Management System
A Python-based library management system that simulates the basic operations of a real library using Object-Oriented Programming (OOP). 
Users can manage books and perform common library tasks through a command-line interface.

## Features
- Add new books
- Search for books
- Borrow books
- Return books
- View all available books
- Input validation to handle invalid operations

## Technologies Used
- Python

## Concepts Used
- Object-Oriented Programming (Classes & Objects)
- Functions
- Lists and Dictionaries
- Loops
- Conditional Statements
- File Handling (if used)

## How to Run
1. Clone or download this repository.
2. Open the project in your preferred Python editor.
3. Run `student_library.py`.
4. Follow the on-screen instructions.
